# Product Pipeline (Антигравити)

Многоагентная система для автоматического создания и развертывания инфопродуктов (курсов, вебинаров, консультаций).

## Описание
Данный проект автоматизирует рутинные процессы при запуске инфобизнеса: от генерации маркетинговой стратегии и копирайтинга до верстки лендингов, создания презентаций, юридических документов и автоматического деплоя. 

## Архитектура (Текстовая схема)
```text
[ Конфигурация (JSON) ] --> [ Оркестратор (pipeline.py) ]
                                      |
       +------------------------------+------------------------------+
       |                              |                              |
[ 1. Маркетинг ]             [ 2. Копирайтинг ]             [ 3. Дизайн ]
- Анализ ЦА                  - Тексты для лендинга          - Верстка HTML (Tailwind)
- Структура воронки          - Email-цепочки                - Стили (Design Tokens)
       |                              |                              |
       +------------------------------+------------------------------+
                                      |
                             [ 4. Видео ]
                             - Сценарии (Reels/Shorts)
                             - HTML-презентации
                             - WebVTT субтитры
                                      |
                             [ 5. DevOps ]
                             - Деплой на хостинг
                             - Настройка доменов
                             - Интеграция форм
```

## Требования (Prerequisites)
- OS: Windows / Linux / macOS
- Python: 3.11 или выше
- Учетные записи (API Keys):
  - OpenAI (для текстовых агентов)
  - Хостинг-провайдер (для автоматического деплоя)
  - Сервис email-рассылок (SendGrid / Mailgun)

## Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <url-репозитория>
   cd product_pipeline
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Если requirements.txt отсутствует, убедитесь, что установлен `asyncio` и модули из стандартной библиотеки).*

3. **Настройка окружения:**
   Создайте файл `.env` в корне проекта и добавьте ваши API-ключи:
   ```env
   OPENAI_API_KEY=sk-...
   HOSTING_API_KEY=...
   SMTP_PASSWORD=...
   ```

## Быстрый старт (Quick Start)

Для запуска полного цикла создания инфопродукта используйте главный оркестратор:

```bash
python pipeline.py
```

Для проверки конфигурации без реального выполнения задач (режим симуляции):
```bash
python pipeline.py --dry-run
```

Для запуска только одного конкретного этапа, например, создания видео-ассетов:
```bash
python pipeline.py --stage video
```

## Описание этапов

1. **Маркетинг (`marketing`)**: Формирование позиционирования, оффера, тарифов.
2. **Копирайтинг (`copywriting`)**: Генерация продающих текстов для посадочной страницы и рассылок.
3. **Дизайн (`design`)**: Рендеринг Jinja2-шаблонов лендинга и форм на основе Tailwind CSS.
4. **Видео (`video`)**: Создание презентаций на HTML/CSS, написание сценариев для Reels, генерация субтитров VTT.
5. **DevOps (`devops`)**: Публикация сгенерированных файлов в продакшн, привязка форм к бекенду.

## Настройка конфигурации (Configuration Reference)
Создайте файл `project_config.json` в корневой директории:
```json
{
  "product_name": "Супер Курс",
  "company_name": "ИП Иванов И.И.",
  "inn": "123456789012",
  "email": "support@example.com",
  "price": "2990"
}
```
Эти данные будут автоматически подставляться в оферту, политику конфиденциальности и лендинг.

## Устранение неполадок (Troubleshooting)

- **Ошибка `FileNotFoundError` при рендеринге шаблонов:** Убедитесь, что папки `templates/` и `legal/` существуют в корне проекта и содержат нужные `.html` файлы.
- **Ошибки кодировки на Windows:** Все файлы читаются и пишутся с явным указанием `encoding='utf-8'`. Проверьте, что ваш терминал поддерживает UTF-8 (выполните `chcp 65001` в cmd/powershell).
